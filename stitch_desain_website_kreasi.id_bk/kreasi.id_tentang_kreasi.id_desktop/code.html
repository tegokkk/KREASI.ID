KREASI.ID Bukan Pengganti Guru BK, Melainkan Jembatan Dialog

KREASI.ID secara tegas bukanlah tes psikologi kaku berbayar dan bukan alat penentu nasib penjurusan otomatis. Kami percaya manusia—khususnya remaja SMP—selalu dinamis, bertumbuh, dan kaya akan potensi yang melampaui algoritma komputer.

Media ini berfungsi sebagai buku catatan refleksi mandiri. Hasil dari lembar kerja, kuis reflektif, atau catatan minat dapat kamu bawa saat sesi konseling santai dengan Guru BK di sekolah untuk membuka obrolan yang lebih mendalam dan bermakna.

Keamanan Data & Ruang Pribadi Siswa

Kami menyadari bahwa catatan refleksi dan eksplorasi bakat adalah ruang paling personal bagi remaja. KREASI.ID dibangun dengan filosofi Privacy by Design:

shield

Tidak ada data pribadi yang dijual, disebarkan, atau dijadikan perbandingan ranking.

save

Tersimpan di Perangkatmu

Semua jawaban kuis, tulisan refleksi, dan target aksi tersimpan secara lokal (Local Storage) di browsermu atau dapat kamu cetak/tulis tangan di buku BK. Tidak diunggah ke server cloud publik.

no_accounts

Tanpa Wajib Bikin Akun

Kamu tidak perlu memasukkan email, nomor HP, atau password yang rumit. Cukup buka halaman, pilih aktivitas, dan langsung mulai tanpa hambatan login.

sentiment_satisfied

Tanpa Tekanan Nilai Rapor

Aktivitas di KREASI.ID tidak menentukan nilai angka di rapor akademis. Tujuannya murni perkembangan kepribadian, pemahaman diri, dan kenyamanan belajarmu.

delete_sweep

Kendali Penuh di Tanganmu

Kamu dapat menghapus catatan refleksi kapan saja dengan sekali klik tombol "Bersihkan Catatan", atau menyimpannya sebagai file PDF rahasia untuk koleksi pribadimu.

Hal yang Sering Ditanyakan Siswa

Apakah hasil kuis KREASI.ID menentukan jurusan SMA/SMK-ku nanti? arrow_drop_down

Tidak secara mutlak. Hasil di sini adalah panduan pemetaan minat dan kecenderungan awal. Keputusan akhir tetap melibatkan diskusi bersama Guru BK, orang tua, dan nilai perkembangan belajarmu secara menyeluruh.

Bagaimana jika teman sekelasku melihat catatanku? arrow_drop_down

Karena data hanya tersimpan di perangkat yang kamu gunakan, temanmu tidak bisa melihatnya lewat akun mereka. Jika kamu menggunakan komputer lab sekolah, pastikan kamu mengklik tombol "Selesai & Hapus Sesi" di pojok kanan bawah.

Apakah platform ini gratis untuk seluruh siswa SMP? arrow_drop_down

Ya, 100% gratis, tanpa iklan komersial, dan tanpa biaya langganan apa pun. KREASI.ID didedikasikan sepenuhnya untuk pendidikan karakter dan pendampingan psikososial remaja.
